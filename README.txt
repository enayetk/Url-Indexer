URL INDEXER ONLINE v1.0

Deploy to Render: create a GitHub repo, upload these files, then Render -> New Web Service -> connect repo -> Free plan -> build: pip install -r requirements.txt -> start: gunicorn app:app.

Features: 500 URL limit, dedupe, validation, reachability, redirects, canonical/robots/noindex inspection, background processing, progress and CSV export.

This does NOT guarantee Google indexing. It reports technical crawl/discovery-related checks.
